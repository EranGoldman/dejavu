Components:
-----------

1. DEVICE (device/)
   - Captures images using Pi Zero W/WH or ESP32-CAM
   - Uploads images when Wi-Fi is available
   - Queues images offline for later upload
   
2. BACKEND (backend/)
   - Flask REST API for image management
   - AI-powered automatic tagging
   - Image storage and search functionality
   - SQLite/PostgreSQL database support
   
3. FRONTEND (frontend/)
   - Simple web dashboard
   - Image gallery view
   - Search and filter capabilities
   - Real-time device status
   
4. DOCS (docs/)
   - Installation guides
   - API reference
   - Architecture overview
   - Development guides
   
5. TESTS (tests/)
   - Unit tests for device and backend
   - Integration tests
   - Test fixtures and utilities
   
6. CONFIGS (configs/)
   - Device configurations
   - AI model settings
   - Deployment configurations

Key Files:
----------

- .env.example: Template for environment variables (API keys, DB URLs, etc.)
- requirements.txt: Common dependencies for development and testing
- LICENSE: MIT License for open-source distribution
- README.md: Comprehensive project documentation and quick start guide
